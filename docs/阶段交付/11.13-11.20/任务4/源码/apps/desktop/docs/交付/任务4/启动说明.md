## 五、导出步骤（需要在装了 Godot 4.6.3 的机器上执行）

推荐用本仓库的检查脚本（先 dry-run 看计划，确认后 `--run`）：

```powershell
python tools/desktop-delivery/export_check.py --root . --dry-run
python tools/desktop-delivery/export_check.py --root . --run
```

它会按顺序执行：版本探测 → `--export-pack` 冒烟 → 用 `--main-pack` 跑 300 帧 →
`--export-release` 模板导出 → 核对产物存在且非空。手动等价命令：

```powershell
mkdir builds\windows
godot --headless --path apps/desktop --export-pack "Windows Desktop" apps/desktop/builds/export-check/Windows-Desktop.pck
godot --headless --path apps/desktop --main-pack apps/desktop/builds/export-check/Windows-Desktop.pck --quit-after 300
godot --headless --path apps/desktop --export-release "Windows Desktop" apps/desktop/builds/windows/KingdomDesktop.exe
```

注意：预设名 **大小写和空格敏感**，必须与 `export_presets.cfg` 的 `name=` 完全一致；当前预设是 `Windows Desktop`。

## 七、常见错误

| 现象 | 原因 | 处理 |
|---|---|---|
| `No export template found at the expected path` | 模板缺失或版本不是 4.6.3 | 安装完全匹配的 4.6.3 模板；`--export-pack` 不需要模板，可先冒烟 |
| `Invalid export preset name: ...` | 预设名大小写/空格不一致 | 用 `Windows Desktop` 的精确写法，命令里加引号 |
| `Can't open file for writing` | 输出目录不存在 | 先 `mkdir builds\windows`；`export_check.py --run` 会自动创建 |
| 找不到 `godot` | 未安装或不在 PATH | 安装 4.6.3，或用 `--godot <exe>` 指定 |
| 首次打开报导入/资源错误 | 干净检出没有 `.godot/` 缓存 | 先 `godot --headless --import` |
| 包内缺 JSON | `include_filter` 未覆盖非资源文件 | 先实机核对，再决定是否加 `*.json` |
| 助手不工作 | 助手 exe 未随包分发/路径不对 | 按约定路径放置；缺失时主游戏应仍可启动（需实机验证） |
