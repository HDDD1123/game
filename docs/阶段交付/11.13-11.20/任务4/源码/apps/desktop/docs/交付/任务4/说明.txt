0. 这一版修了什么
-----------------
中控在 Godot 4.6.3 上实测出 6 项失败，已全部修掉；另外自查时又发现并修了 2 项：

1) startup_service.gd：Godot 的 JSON.parse_string 把数字解析成 float（4 -> 4.0），
   原代码只认 TYPE_INT，于是真实 v4/v5 存档会被误判成"缺整数版本 -> 损坏"。
   已改为接受"整数值的 float"，非整值才判损坏。        -> 3 项失败转绿
2) history_renderer.gd：空事实时 ending_exited_midway（只要求 fact_absent ending）也命中，
   "没有记录"被当成"中途退出"。已加 has_evidence：facts 与 counters 都空时直接走中性兜底。
   -> 1 项转绿
3) test_narrative_render.gd：断言"所有 fixture 的预览模式都带出 preview_only"，
   但两个 fixture 本身有 ending 事实，永远不可能满足。已改成按证据条件断言：
   无 ending 事实且 months_played >= 1。没有放宽数据去迎合测试。   -> 2 项转绿
4) settings_store.gd set_value：`var current := load_preferences().preferences` 无法推断类型，
   整个 settings 分节编译失败，平台测试因此静默少跑 14 项（中控看到的 34 项就是残缺计数）。
   已显式标注 Dictionary。                                   -> 48 项补齐，0 失败
5) settings_store.gd RANGES：边界用 Vector2 存，分量是 32 位浮点（1.6 -> 1.60000002），
   写进去读回来不相等。已改成 [min, max] 数组 + float()。      -> 精度断言转绿
