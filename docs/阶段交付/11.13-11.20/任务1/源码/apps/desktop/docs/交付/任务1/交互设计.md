# T1-01 交互设计与美术规格

> 任务1 · 画面与操作。日期：2026-11-15。基线：v0.4.2（`d052b27`）+ 任务文档 `631df2c`。

## 一、主路径图

```
启动
 └─ 首屏：继续 / 新建 / 诊断（坏档、无档、权限）
      ↓
经营（街景常驻）
 ├─ 信息栏：日期｜人口/容量｜粮仓｜待收｜木材｜矿石｜每批产粮｜需求
 ├─ 农田：点击=有成熟先收，无成熟=助耕(+5%)
 ├─ 建筑详情：民居（扩建）/ 铁匠铺（升级）/ 农田（升级+研究入口）
 ├─ 研究面板：三树 × 6 节点（本轮 3 节点），显示累计/可用/前置/原因
 └─ 操作行：推进一个月｜农田详情｜研究｜保存｜读取｜展开管理
      ↓
事件（暂停）
 ├─ 街景直接：接纳 / 拒绝（缺床时直接打开民居扩建）
 ├─ 预览：接纳后人口、每月口粮、木材增量、缺床数
 └─ 期限与后果：默认后果 + 明确反馈
      ↓
远征
 ├─ 选地点/人数/目标 → 预览费用（粮+木）、战力、风险
 ├─ 出征（不推进月份）→ 每月战报（房间推进/损失）
 └─ 归队：战利品入库，只看真实战报
      ↓
保存
 ├─ 保存（格式5/4）/ 读取 / 重开
 └─ 关闭：保存并退出 / 直接退出 / 取消（保存失败保持窗口）
```

## 二、基线前 10 分钟的操作阻碍（按影响排序）

1. **信息栏单行过长**：720 宽时会被截断或换行，「待收」不在首屏，玩家先看到的是不重要的数字。
2. **农田点击语义不明**：点下去是「收」还是「助耕」没有提示，玩家不敢点。
3. **街景缺少建筑入口**：v0.4.2 只有「农田详情」，民居/铁匠铺要从普通视图进。
4. **研究面板看不到点数来源**：只显示「可用」，不知道累计多少、下一点从哪来。
5. **暂停状态不显眼**：事件暂停只在信息栏加「⚠ 流民待决定」，没有统一「时间已暂停」标识。
6. **远征预览不在街景**：要展开普通视图才知道出征花多少。
7. **保存失败提示易错过**：只写在 message 行，小窗里容易被忽略。
8. **置顶开关只在普通视图**：街景没有，挂机时想置顶要展开。
9. **手动推进 vs 自动时间的区别**：新手不知道当前是手动模式。
10. **预留地块没有「未来可建」说明**：只显示「暂无生产」，看不出这是给商栈/前哨留的。

## 三、临时美术规格（可直接制作）

- **画布**：街景高 280（150% DPI 下可用区约 2536×280）；左右边距 10。
- **建筑区域**：每槽约 150×90，7 槽均分；图片底边对齐基线 y≈220，保持比例、不拉伸。
- **源图**：1x 150×90，2x 300×180，透明 PNG；视角统一 2.5D 斜俯视，光从左上来。
- **色板**：土黄 `#C8A96A`、木 `#8B5A2B`、石 `#7A7A7A`、草 `#6B8E4E`、夜蓝 `#2E3A4A`。
- **占位**：色块 + 轮廓 + 文字；`texture` 为空或路径错误时回退文字，点击区域不变。
- **状态**：正常 / 悬停 / 禁用 / 缺资源 四态；农田另加 生长（幼苗）/ 成熟（金黄）/ 满批（堆叠）三态，用同图轻量变化。
- **文字**：主 14—15px，次 11—12px；对比度 ≥4.5:1；不靠缩小字号塞信息。
- **人才**：48×48 头像占位，配职业/性格标签。
- **图标**：优先单色线性，避免与建筑图抢视线。

## 四、T1-02 的落地范围（本轮代码）

只做「布局与信息层级」：
1. 信息栏拆成两段：核心（日期/人口/粮仓/待收/风险）+ 次要（木材/矿石/每批/需求），720 宽时次要可折进详情。
2. 街景补「时间状态」：手动推进/已暂停 + 下次结算提示。
3. 街景补「待决事件」醒目条与「缺粮风险」提示。
4. 农田槽位显示「可收/助耕」动作词，减少误点。
5. 预留地块显示「预留：商栈/前哨营地」，不再只写「暂无生产」。
6. 不改 core 规则、不改存档格式；只改 `ui/main.gd`、`data/building_slots.json` 与 `tests/task1/`。
