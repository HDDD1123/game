3. 工程已位于 apps/desktop/，直接导入其中的 project.godot。Godot 的 res:// 根目录是 apps/desktop，不是整个 Git 仓库。保留原工作目录中的 prototypes/text/ 和所有大纲、调研、计划资料。

## 004B：窗口与界面（A通过后继续）

- 普通模式：可以看到资源、建筑、流民选择、远征设置、战报、手记及存读档。
- 小窗模式：先尝试约960×260，只保留资源收支、当前事件/远征摘要、推进与展开按钮。具体宽高随可用屏幕调整，不能把整张界面硬挤小；展开后恢复操作区。
- 使用屏幕可用区域定位，避免遮住任务栏；支持拖动。先保留系统边框，不将无边框、透明背景或鼠标穿透设为本次通过条件。
- 可选置顶，默认关闭；点击切换后能恢复普通窗口。刷新状态不能反复抢走其他应用焦点。
- 窗口位置、尺寸、模式与置顶状态保存到独立窗口配置。重新打开或断开副屏后，将窗口限制在仍可见的屏幕区域。
- 关闭前提示保存/直接退出/取消；保存失败时保留窗口并显示原因。正常存档用 user://kingdom-save-v3.json，不写安装目录。
- 继续手动推进月份，关闭不补算时间。不要在这一步偷偷添加计时器。

主界面只调用 game.act / snapshot / view、SaveStore；不要直接写 _state。重复点击、陈旧事件ID和资源不足仍由内核拦截。若发现内核问题，附最短复现步骤交回 GPT；必要修复需单独记录，不能默默改变数值。
