# 任务4：Windows后台打字助耕独立试验

负责人：新DSH-C。分支：`dsh/task4-typing-v05`。目标：游戏失焦、玩家在其他普通应用打字时，只汇总活动次数用于助耕；功能默认关闭，可立即停用。

先读 [总览](四机并行总览.md) 和 [接口约定B](四机接口约定.md)。参考 `input-systems` 的输入隔离/去重原则与 `godot-gdscript-headless-testing`；该skill不实现Windows全局输入，不可把Godot InputMap当作后台监听。12点，四个里程碑各3点。

## 里程碑1：普通用户可运行的计数助手（3点）

- 在 `tools/windows-typing/` 实现独立辅助程序及构建说明。优先选本机已有可维护工具链；可用独立C#/.NET或原生Win32等，说明构建依赖和运行依赖，不把Godot工程升级成.NET版。
- 只在显式启动后工作，后台接收有效按下，排除长按自动重复及单独修饰键；按协议定期输出汇总。保留键码只为内存去重，不记录文字/键序/窗口标题/剪贴板，不发送网络请求。
- 关闭、父进程退出或管道断开时退出；无自启动，无隐藏常驻服务，不要求管理员权限。不能接收某类高权限窗口输入时记录限制，不能靠关闭防护解决。
- 技术路线先在本机验证失焦输入是否真的可收到，再完成其余包装，避免只做前台演示。

## 里程碑2：Godot协议桥与生命周期（3点）

- 新建 `apps/desktop/platform/typing/typing_bridge.gd`，实现约定的start/stop/drain_count/status；平台层完全不知道粮食和时间的计算。
- 非阻塞读取，校验协议/整数/计数上限/序号/单行长度；重复数据只消费一次，坏包不会阻塞主线程或无限积攒内存。
- 默认关闭；重复开关不多开助手；助手崩溃/找不到/权限不足时显示可理解的错误，游戏仍能点击助耕；切换后不补发旧计数。
- 限制本地缓冲，处理助手大量输出、输出半行、长时间无输出与退出；具体4.6.3进程/管道API先在本机确认。

## 里程碑3：独立助耕演示（3点）

- 在 `apps/desktop/experiments/task4/` 新建演示场景，使用当前Kingdom，带“开启后台活动/关闭”、本批活动计数、生长进度、收取与模拟暂停。
- 当前基线尚无任务2时间接口，演示用自己的“允许助耕”开关和 `snapshot().pending/ended` 判断，循环取走所有计数；暂停/满田时停助手，恢复时按接口约定建立新会话，不把未发出的半批旧输入奖励到新阶段。通过现有 `assist_farm(source=typing,count=n)` 提交，点击也走现有核心，以真实共用额度验证。
- 本演示不添加自动计时、不改core、不依赖任务2分支。演示暂停只验证输入丢弃逻辑，不冒充整合版的时间暂停；最终由GPT接入view.clock和正式开关。
- 不改项目主场景，给出单独启动命令。游戏重启后仍默认关闭，失败时可继续常规演示。

## 里程碑4：协议测试与实机证据（3点）

- `apps/desktop/tests/task4/` 覆盖合法计数、重复/倒序、负数/小数/超限、超长/残缺数据、反复开关、停止后drain为0和助手退出。使用模拟管道的数据测试不能替代后台实测。
- 在记事本等普通应用中打字，证明游戏失焦仍收到汇总；记录单击、长按、暂停后恢复、关闭后输入、辅助进程意外退出、主程序关闭后无残留进程。人工和操作系统输入自动化分别标注，不录入真实账号密码或私人正文。
- 检查输入输出协议与日志不含按键内容，依赖缺失和不支持平台能正常报错。测一次关闭、开启但空闲、连续输入三个状态下的CPU/内存，写机器配置和采样方法，不拿通用阈值硬凑结果。
- 报告放 `apps/desktop/docs/交付/任务4/README.md`，附构建/启动命令、协议版本、测试摘要、支持范围和未测项。若交演示包，说明是否依赖运行时；从干净目录实际试运行，源码中不混入helper.exe或构建输出。

## 修改范围与完成标准

只新增 `tools/windows-typing/`、`apps/desktop/platform/typing/`、`apps/desktop/experiments/task4/`、`apps/desktop/tests/task4/` 和自己的交付目录。不改main.gd、core、project.godot、全局.gitignore或旧tests。仓库现有 `.gitignore` 会忽略 `*.csproj` 等扩展名，如需它作为助手源码，用明确单文件 `git add -f`，不要放开整个bin/obj目录。

完成标准：默认关闭、失焦可计数、关闭立即停止、无内容记录、计数不重复、助耕仍受核心上限控制。遇到Windows工具/接口阻塞时，交可运行协议测试、复现命令和实际错误，明确哪些只做了模拟；不把普通前台按键当作后台功能交付。
