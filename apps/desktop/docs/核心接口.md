# DSH接线约定

## 创建与读取

```gdscript
const Kingdom = preload("res://core/kingdom.gd")
const SaveStore = preload("res://core/save_store.gd")
var game = Kingdom.new()
var saves = SaveStore.new()
var state = game.snapshot()
var presentation = game.view()
```

snapshot() 返回深复制。UI不能修改内部 _state。view() 提供日期、城内人数、粮食/木材产量、需求、下次流民、建设价格及地点配置，UI直接显示，不复制计算公式。

## 操作

act(command, args={}) 返回 {ok, message, state, view}。失败操作不修改游戏状态。窗口提示 message 并重绘；按钮置灰只是提示，内核仍校验所有操作。

| command | args |
|---|---|
| advance_month | 无 |
| build_housing | 无 |
| improve_agriculture | 无 |
| upgrade_forge | 无 |
| accept_refugees | {event_id: 当前画面对应的pending.id} |
| reject_refugees | 同上 |
| dispatch | {site: ruins或mine, mode: explore或clear, troops: 整数} |
| restart | 无；不会删除磁盘存档 |

dispatch_problem(args) 返回不可出征原因，空字符串表示当前允许。仍需通过act执行，不能只做UI校验。

人口始终含在途队伍。派出与返回不增减总人口，只改变城内劳动人数；死亡才扣总人口。战利品归队才入库。缺粮先结算伤亡，再结算该月战斗。

## 保存

```gdscript
var result = saves.save_game(game)
var result2 = saves.load_game(game)
```

存档版本3，默认user://kingdom-save-v3.json；写成功后保留上一份.bak。失败返回原因，读取失败保持当前进度。不要让UI自行序列化半份状态。

网页v0.2存档不兼容本格式，尚未实现导入器。不能以“让玩家重开”掩盖桌面同版本读档缺陷。启动、读档、窗口变化都不得调用advance_month。

## 程序边界

core/kingdom.gd没有Node、Timer、窗口、网络或文件操作。core/save_store.gd只负责存档。UI与后续绘画、动画放在ui/；窗口布局与设备差异由桌面层处理。

以后的自动计时只应在获准推进时提交advance_month命令。事件暂停、用户暂停、关闭应用都不提交命令；不根据墙上时间补算月份。
