背景：任务2 的原负责人未交付，中控 DSH 直接实现运行内核的核心部分。

已完成（18 点：T2-02 / T2-03 / T2-04）
-------------------------------------
1) T2-02 在线统一时钟
   - `game.act("set_auto_running", {enabled})` 开启/暂停
   - `game.tick(elapsed_ms)`：单次 0—1000ms，越界拒绝；整数余量累计
   - `game.set_time_blocked(reason, blocked)`：会话级阻塞集合，原因独立增删
   - `view().clock`：running / blocked / pause_reasons / month_elapsed_ms /
     month_duration_ms(=150000) / remaining_ms / month_progress / can_step
   - 新局、重开、读档后自动时间默认关闭
   - 暂停/阻塞/事件/结束时 tick 不推进；长卡顿（>1000ms）由 SessionController 丢弃

2) T2-03 连续生产与月结算
   - 月末不再额外整批生长；生长只由 tick 的经过时间产生
     （每 150000ms = 本月自然工作量，余数累计）
   - 满田/无人劳动时丢弃该段生长，不攒隐藏奖励
   - 到月界先完成最后一段生长，再按「扣口粮→饥饿→月份切换→战斗→来访」结算
   - 手动 `advance_month`（自动关闭时）补齐本月剩余时间后结算，结果与旧行为一致
   - 自动运行时 `advance_month` 被拒绝

3) T2-04 格式5与迁移
   - `user://kingdom-save-v5.json`；snapshot 增加
     `clock{version, month_elapsed_ms, growth_remainder}`
   - 读取优先级 5→4→3；较新文件存在但损坏必须报错，不静默回退
   - 格式4迁移：补 clock 置0，保留农田/技能/事件/远征，不追补产出
   - 格式3迁移：沿用原规则补齐再进入5
   - `.tmp` + `.bak` 原子写策略保留

4) SessionController（runtime/session_controller.gd）
   - `attach_game` / `command` / `set_block` / `refresh_after_load` / `state_changed`
   - 唯一 tick 调用方；连续进度最多每秒 4 次通知，命令结果立即通知
   - 重复 attach 不重复计时
